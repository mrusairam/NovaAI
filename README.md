# Nova AI Solutions – Website

Welcome to the official website repository for **Nova AI Solutions**, a modern AI automation agency focused on helping businesses grow through smart, scalable automation.

---

## 🚀 Project Overview

This is a fully responsive, clean, and modern website built using **React + Tailwind CSS**. It highlights Nova AI's core services, client testimonials, contact methods, and a professional call-to-action system using modals.

---

## 🧩 Features

- ⚡️ **Hero Section** with compelling AI branding
- 🧠 **Services Grid** with animated cards
- 🤖 **Client Testimonials** (slider-based)
- 📍 **Contact Section** with map & cards
- 📩 **Global Modal System** – easily trigger modals from anywhere
- 📱 **Mobile Responsive** using Tailwind utility classes
- 🌐 **SEO-ready** structure

---

## 🛠 Tech Stack

- [React](https://reactjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/) (scroll animations)
- [React Icons](https://react-icons.github.io/react-icons/) (iconography)

---

## 📁 Folder Structure

```

src/
│
├── assets/              → Images & icons
├── components/          → Global components like Footer, Modal, Navbar
├── Main/                → Main sections (Hero, About, Services, Contact)
├── Modal/               → Modal system with context API
├── App.jsx              → Main layout

````

## 📦 Setup Instructions

> Make sure Node.js is installed on your system.

### 1. Clone the repository
```bash
git clone https://github.com/your-username/nova-ai-site.git
cd nova-ai-site
````

### 2. Install dependencies

```bash
npm install
```

### 3. Run the project locally

```bash
npm run dev
```

Project will be available at `http://localhost:5173` (or as shown in terminal).

---

## 🖼 Changing Content
